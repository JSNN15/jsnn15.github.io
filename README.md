# jsnn15.github.io

Portafolio de Julián Neira Nova, ingeniero eléctrico: simuladores de procesos, pruebas con datos reales y herramientas de automatización.

- `planta-virtual/`: sala de control SCADA de una planta LX-SX-EW de cobre, con secuencias, alarmas ISA-18.2 y un modelo trazable a fuentes.
- `simulador-ew/`: simulador de una nave de electroobtención de cobre (ley de Faraday, cortocircuitos y su detección).
- Laboratorio virtual de flotación: repositorio [lab-virtual-flotacion](https://github.com/JSNN15/lab-virtual-flotacion).
- [prama-agent](https://github.com/JSNN15/prama-agent): equipos de agentes de IA en un servidor propio.

Todo corre en el navegador, sin servidores. Proyectos personales.
